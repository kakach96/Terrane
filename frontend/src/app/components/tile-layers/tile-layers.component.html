瓦片服务 通过 /tiles/{layer}/{z}/{x}/{y} 访问瓦片，支持 gridset 参数

瓦片 URL 格式

/tiles/{layer}/{z}/{x}/{y}?gridset=EPSG:4326

支持的 Gridset

  • EPSG:4326 — 全球地理坐标系
  • EPSG:3857 — Web Mercator

WMTS 服务

OGC WMTS 1.0.0 标准服务已启用，支持以下操作：

  • GetCapabilities — /wmts?SERVICE=WMTS&REQUEST=GetCapabilities
  • GetTile — /wmts?SERVICE=WMTS&REQUEST=GetTile&LAYER=...&TILEMATRIXSET=...&TILEMATRIX=...&TILEROW=...&TILECOL=...
  • RESTful — /wmts/{layer}/{tileMatrixSet}/{tileMatrix}/{tileCol}/{tileRow}
  • GetFeatureInfo — /wmts?SERVICE=WMTS&REQUEST=GetFeatureInfo&...
